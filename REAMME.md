# Weather & Location Dashboard

## 📌 Project Overview

This project was developed as part of the Advance Soft Logics Remote Internship Program (Week 3).

The application allows users to search for a city and view live weather information using the Open-Meteo API. It also stores recent searches using localStorage and provides a clean, responsive interface.

---

## 🚀 Features

- Search weather by city
- Live weather data
- 3-Day weather forecast
- Loading indicator
- Error handling
- Recent searches using localStorage
- Click recent search to reload data
- Current Location (Geolocation)
- Temperature Unit Switch (°C / °F)
- Responsive Design
- Modular JavaScript (ES Modules)

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API
- Async / Await
- Open-Meteo Weather API
- Open-Meteo Geocoding API
- LocalStorage
